# cancer_metastasis_LMC

This project uses latent methylation components (LMCs) derived from DNA methylation deconvolution to study lymph node metastasis across six TCGA cancer types (BLCA, BRCA, COAD, HNSC, LUAD, and STAD).
Analyses
- Compare LMC proportions between node-negative (N0) and node-positive (N+) tumors.
- Evaluate cancer-specific and pan-cancer LMCs for predicting lymph node metastasis.
- Assess associations between LMCs and patient survival.
